# 1. PRD/TASK: Phylax Go SDK

## Project Name

`phylax-go`

## Goal

Build the official Go SDK for Phylax server-side integrations.

This SDK will be used by customer backends to:

1. Introspect Phylax session tokens.
2. Protect sensitive HTTP routes.
3. Provide framework-agnostic middleware primitives.
4. Support custom adapters later.
5. Provide clean typed request/response models matching the Phylax API.

The SDK should not perform Google Play Integrity or Apple App Attest verification directly. That responsibility remains inside the Phylax service.

## Current Phylax API Context

Phylax already exposes:

```text
POST /v1/apps/{app_id}/challenges
POST /v1/apps/{app_id}/attestations/verify
GET /v1/apps/{app_id}/setup-checks
POST /v1/sessions/introspect
```

The Go SDK should primarily consume:

```text
POST /v1/sessions/introspect
```

for backend route protection.

It may optionally expose challenge and verification calls for internal/testing use, but the main production use case is server-side middleware.

## Public API

Create a `Client`.

```go
type Client struct {
    // internal fields
}

type Config struct {
    BaseURL    string
    ProjectID  string
    AppID      string
    APIKey     string
    HTTPClient *http.Client
    Timeout    time.Duration
}
```

Constructor:

```go
func New(config Config) (*Client, error)
```

Methods:

```go
func (c *Client) Introspect(ctx context.Context, token string) (*IntrospectResponse, error)
```

Optional:

```go
func (c *Client) CreateChallenge(ctx context.Context, appID string, req CreateChallengeRequest) (*CreateChallengeResponse, error)

func (c *Client) VerifyAttestation(ctx context.Context, appID string, req VerifyAttestationRequest) (*VerifyAttestationResponse, error)
```

## Models

Implement strongly typed models matching the API.

```go
type IntrospectRequest struct {
    Token string `json:"token"`
}

type IntrospectResponse struct {
    Active  bool                `json:"active"`
    Error   string              `json:"error,omitempty"`
    Session *AttestationSession `json:"session,omitempty"`
}

type AttestationSession struct {
    ID        string    `json:"id"`
    AppID     string    `json:"app_id"`
    InstallID string    `json:"install_id"`
    Platform  Platform  `json:"platform"`
    Subject   string    `json:"subject"`
    Action    string    `json:"action"`
    RiskLevel string    `json:"risk_level"`
    IssuedAt  time.Time `json:"issued_at"`
    ExpiresAt time.Time `json:"expires_at"`
}

type Platform string

const (
    PlatformAndroid Platform = "android"
    PlatformApple   Platform = "apple"
    PlatformFirebase Platform = "firebase"
)
```

Remember that Phylax API responses are wrapped:

```json
{
  "error": false,
  "message": "success",
  "data": {}
}
```

So implement:

```go
type APIResponse[T any] struct {
    Error   bool   `json:"error"`
    Message string `json:"message"`
    Data    T      `json:"data"`
}
```

## Middleware

Create standard HTTP middleware.

```go
type MiddlewareConfig struct {
    HeaderName string
    Required   bool
    OnError    func(w http.ResponseWriter, r *http.Request, err error)
}
```

Default header:

```http
X-Phylax-Token: PHYLAX_SESSION_TOKEN
```

Middleware signature:

```go
func (c *Client) Middleware(config MiddlewareConfig) func(http.Handler) http.Handler
```

Behavior:

1. Read `X-Phylax-Token`.
2. If missing and required, return `401`.
3. Call `Introspect`.
4. If inactive, return `403`.
5. Add session to request context.
6. Continue to next handler.

Context helpers:

```go
func SessionFromContext(ctx context.Context) (*AttestationSession, bool)
```

## Error Handling

Create typed errors.

```go
var (
    ErrMissingToken = errors.New("phylax: missing token")
    ErrInactiveToken = errors.New("phylax: inactive token")
    ErrInvalidConfig = errors.New("phylax: invalid config")
)
```

HTTP/API errors should include:

```go
type APIError struct {
    StatusCode int
    Message    string
    Body       string
}
```

## Security Requirements

* Never log Phylax tokens.
* Never log customer API keys.
* Redact token values in errors.
* Support custom `http.Client`.
* Use request contexts and timeout.
* Reject empty `BaseURL`.
* Reject empty `AppID` when required.

## Testing

Write tests for:

1. Client constructor validation.
2. Successful introspection.
3. Failed introspection.
4. API error handling.
5. Missing token middleware behavior.
6. Inactive token middleware behavior.
7. Active token adds session to context.
8. Custom header name.
9. Timeout/context cancellation.

Use `httptest.Server`.

## Acceptance Criteria

The SDK is complete when:

* A customer can initialize the Go SDK with `BaseURL`, `ProjectID`, `AppID`, and `APIKey`.
* A customer can protect a route using middleware.
* The SDK calls `/v1/sessions/introspect`.
* Active sessions are attached to request context.
* Missing/inactive tokens are blocked.
* Tests pass.
* README includes setup and usage examples.

## README Example

```go
phylaxClient, err := phylax.New(phylax.Config{
    BaseURL:   "https://api.phylax.dev",
    ProjectID: "project_123",
    AppID:    "app_123",
    APIKey:   os.Getenv("PHYLAX_API_KEY"),
})

if err != nil {
    log.Fatal(err)
}

mux := http.NewServeMux()

protected := phylaxClient.Middleware(phylax.MiddlewareConfig{})(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
    session, _ := phylax.SessionFromContext(r.Context())
    _ = session

    w.WriteHeader(http.StatusOK)
    w.Write([]byte("trusted request"))
}))

mux.Handle("/sensitive", protected)
```
